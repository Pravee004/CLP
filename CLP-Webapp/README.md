# CLP

CLP landing page — React + Vite + TypeScript + Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Other scripts:

```bash
npm run build     # type-check + production build
npm run preview   # preview the production build
npm run lint       # oxlint
```

## Project architecture

This project follows a fixed folder structure and a set of permanent
development rules that apply to every future feature/section added to the
codebase. **Read these before adding any code:**

- [docs/FOLDER_STRUCTURE.md](docs/FOLDER_STRUCTURE.md) — where everything lives
- [docs/COMPONENT_GUIDELINES.md](docs/COMPONENT_GUIDELINES.md) — where components belong and how to reuse them
- [docs/STYLING_GUIDELINES.md](docs/STYLING_GUIDELINES.md) — Tailwind, global CSS, and component CSS rules
- [docs/DEVELOPMENT_RULES.md](docs/DEVELOPMENT_RULES.md) — the permanent rules for every future task

## Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS v4 (`@tailwindcss/vite`)
